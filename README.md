# CosmicBiomass

A modern, pythonic Python package for cosmic biomass analysis and modeling.

## Features
- Modern Python 3.9+ code style
- Poetry for dependency management
- `src/` layout for clean imports
- Ready for testing and documentation

## Directory Structure

```
cosmicbiomass/
├── README.md
├── pyproject.toml
├── src/
│   └── cosmicbiomass/
│       └── __init__.py
├── tests/
│   └── __init__.py
```

## Setup

1. Install Poetry if you haven't already:
   ```bash
   pip install poetry
   ```
2. Install dependencies:
   ```bash
   poetry install
   ```
3. Run tests:
   ```bash
   poetry run pytest
   ```
