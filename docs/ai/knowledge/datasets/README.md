# datasets/

Durable knowledge about **input and reference data**: formats, schemas, fixtures, and
external data sources the project depends on. One dataset or source per file.

A good dataset page:

- describes the data's shape (columns/fields, types, units) and where it comes from,
- notes edge cases, quirks, and validation expectations,
- points to the code that reads or produces it,
- ends with **Related links**.

Use this for knowledge that outlives a single task — not for one-off sample files. Add new
pages to [`../index.md`](../index.md) and [`../log.md`](../log.md).
