# raw/

Curated **source material** that feeds the knowledge base but isn't a finished page yet:
research notes, issue syntheses, meeting summaries, excerpts from external references.

These are **inputs, not canonical explanations.** Their job is to be distilled into proper
`concepts/`, `systems/`, `datasets/`, or `runbooks/` pages. Keep raw material here only while
it's useful; once its content is captured in a real page, link the two or remove the raw file.

Don't treat a `raw/` file as authoritative — always prefer the distilled page. Add anything
worth tracking to [`../index.md`](../index.md) and [`../log.md`](../log.md).
