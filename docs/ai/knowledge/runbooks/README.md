# runbooks/

Operational guides for **recurring tasks** — release flow, onboarding a new contributor,
deploying, rotating credentials, or debugging a known class of issue. One procedure per file.

A good runbook:

- states when to use it and any preconditions,
- gives numbered, concrete steps (real commands, real paths),
- includes a recovery / rollback path where relevant,
- ends with **Related links**.

Runbooks describe *how to do a thing*; conventions describe *rules to follow*; skills are
*procedures the agent runs*. If a procedure is mainly for the agent, consider
[`../../skills/`](../../skills/) instead. Add new pages to [`../index.md`](../index.md) and
[`../log.md`](../log.md).
